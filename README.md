# Text Generation with GPT-2

## Objective

The objective of this project is to train and fine-tune a GPT-2 model to generate coherent and contextually relevant text using a custom dataset.

## Technologies Used

* Python
* Google Colab
* GPT-2
* Hugging Face Transformers
* PyTorch

## Project Workflow

1. Installed required libraries
2. Loaded GPT-2 pretrained model
3. Created and uploaded custom dataset
4. Fine-tuned GPT-2 on dataset
5. Generated text using trained model

## Result

The GPT-2 model successfully generated coherent text related to Artificial Intelligence after training on a custom dataset.

## Files Included

* `GPT2_Text_Generation.ipynb` → Main notebook
* `dataset.txt` → Training dataset
* Screenshots → Training and output proof

## Learning Outcomes

* Understanding GPT-2 architecture
* Fine-tuning transformer models
* Text generation using NLP
* Working with Hugging Face Transformers
